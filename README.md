# Online-Auktion Benedikt Notter: Prototyp

Klickbarer Prototyp zum Ausprobieren. Das ist keine echte Auktion: Gebote gelten nicht, es gehen keine Mails raus,
und alles bleibt im eigenen Browser. Bitte keine echten Daten eintragen.

Titel, Preise und Masse sind Beispiele. Die Bleistiftbilder sind aus den Farbbildern erzeugte Platzhalter und keine
Werke von Benedikt Notter.
